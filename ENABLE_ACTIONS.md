# 🤖 Kích hoạt GitHub Actions

## Bước 1: Enable GitHub Actions
Vào: https://github.com/blogecoin/oke/settings/actions
- Chọn "Allow all actions and reusable workflows"
- Click "Save"

## Bước 2: Chạy thử Bot
Vào: https://github.com/blogecoin/oke/actions
- Click workflow "🤖 Autonomous Daily Bot"
- Click "Run workflow"
- Click "Run workflow" button

## Hoặc chờ Bot tự chạy lúc 00:00 UTC hàng ngày!
